Strands, as a trained neural CA

Spectacle's game draws a line from a tapped tile along the player's rule, tile to tile. Here a small neural network runs on every hexagon, step after step, and has to draw that line itself: each tile sees only its own type and which way round it is, and the tapped tile alone is told the rule and the tapped chord (by older weights at every step; by newer ones once, at the tap, as in the game, after which the line has to keep itself going). Tap tiles to start strands, each with its rule, and compare what the network draws with the true strand underneath. Fill NCA · Hand-written CA · Source on GitHub
